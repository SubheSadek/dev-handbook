## ➕ Adding a note

1. Copy [`TEMPLATE.md`](TEMPLATE.md) into a category folder, for example `docker/compose.md`. Create the folder if the category is new.
2. Fill in the sections and delete the ones that don't apply.
3. Add a row to the [Index](#-index), grouped with its category.
